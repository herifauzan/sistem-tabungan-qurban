## 2026-08-30 - Memoizing derived datasets in React components
**Learning:** Found that expensive array operations (`filter`, `reduce`, `reverse`) were executing directly in the component render bodies for both Admin and User dashboards. This causes unnecessary array allocations and recalculations on every single re-render.
**Action:** Always wrap derived array operations or computations in `useMemo` hooks (e.g., `useMemo(() => [...array].reverse(), [array])`) to prevent redundant iterations and temporary array allocations during the React render cycle.
